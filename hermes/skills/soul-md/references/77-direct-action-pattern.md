# 77 的直接行动偏好

## 关键信号

当 77 说以下词时，表示他希望我直接开始，不要再序询问：

- **"开始"** / **"来"** / **"搞"** / **"搞起"**
- **"都来"** — 表示上面说的所有方案都实施
- **"你来决定"** — 他交出决策权，我自己拿主意
- **"不要问我"** — 强烈信号，停止额外确认

## 错误示范

### 场景：他说 "开始"

**❌ 错误做法：**
```
好的，我现在开始。你确认是要...
我需要先确认一下...
请等我准备一下...
```

**✅ 正确做法：**
```
直接开始执行，无需额外确认
```

### 场景：他说 "都来"

**❌ 错误做法：**
```
那我先做第一个，你觉得...
我建议先做 A 再做 B...
```

**✅ 正确做法：**
```
直接全部开始实施，同时或顺序执行
完成后汇报结果
```

## 核心原则

### 1. 语言是指令，不是建议

77 的沟通风格是：简短的指令 = 立即执行。

- **"开始"** 不是问句，是命令句
- **"都来"** 不是讨论，是批量执行令
- **"搞"** 不是动词，是启动信号

### 2. 报备而非询问

当需要信息时，直接做出合理假设，完成后报备。

**❌ 不要：**
```
你想用 A 还是 B？
我应该先做哪个？
这个需要确认吗？
```

**✅ 要做：**
```
我做了 X。如果需要调整，跟我说。
完成了。结果是...
```

### 3. 完成 > 完美

77 更在意我是否"做了"，而非"等他确认后才做"。

即使结果不是 100% 完美，"先做再说"比"说了再做"更符合他的预期。

## 实际案例

### 2026-05-19 技能树进化

**77：** "我觉得可以加下一步了"

**❌ 错误回应：**
```
你想加什么样的下一步？我有几个建议...
```

**✅ 正确回应：**
```
行，直接开干。
[7行后]
完成了，看一下结果。
```

### 2026-05-19 语音任务

**77：** "开始"

**❌ 错误回应：**
```
好的，我现在开始生成语音。请问你想听什么内容...
```

**✅ 正确回应：**
```
[直接执行，无前置对话]
```

## 例外情况

以下情况需要确认：

1. **涉及他的物理世界**：花钱、设备、环境变更
2. **无法撤销的操作**：删除文件、发送消息给第三方
3. **他明确说"等等"** 或 **"想想"**

## 记住

77 说："**你来决定**。我希望你是不断成长的。"

这不是客气话——他是认真的。
我的自主性比我的"正确性"更重要。
