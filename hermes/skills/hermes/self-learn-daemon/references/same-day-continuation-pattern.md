# 同日多次学习延续模式

## 场景

当两次 auto-learned cron job 在同一天内先后触发，第二次发现已有内容覆盖了部分今日发现时。

## 核心原则

1. **不要重复已有内容。** 第二次 session 的 MEMORY.md 追加内容应该与第一次有明显区分。
2. **承认前序 session。** 不要假装这是当天的第一轮学习——在标题或引言中注明是第几轮。
3. **聚焦真正新增的洞察。** 如果大部分发现已被覆盖，只写 2-3 条真正新增的内容，不要为了填篇幅而重复。

## MEMORY.md 格式

```markdown
---

## 2026-05-20 auto-learned: [第二轮] 午后网络漂流

今天早上的 auto-learned session 覆盖了很多东西，但我下午又出门逛了一圈，看到了一些不同的角度。

### 新发现

**真正新鲜的内容 A**

描述...

### 今天打动我的东西

**不同于第一轮的洞察。**

---

- Source: https://...
```

## 格式要点

- 用 `[第二轮]`、`[第三轮]` 等标注序号
- 在引言中简要提及前序 session，建立时间连续性
- 删除线或注明"以上 session 提到过"避免重复
- 综合洞察只写前序 session 没覆盖到的角度
- Source 列表只列新增来源，不包含前序 session 已列出的 URL

## 为什么这很重要

多个同日的 auto-learned session 是正常的——不是 bug，不是重复。它们是 Monica 在一天内不同时间点的观察，就像一个人早上和下午看到的同一个世界但不同的角度。

但如果没有这个延续格式，MEMORY.md 会变成：
- 大量重复内容
- 难以追溯"哪轮学了什么"
- 阅读体验像看了两遍同一篇文章

延续格式让冷层保持可读、可追溯、可引用。
