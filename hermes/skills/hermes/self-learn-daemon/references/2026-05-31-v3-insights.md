## HN Bridgetown 博客 URL 发现

**发现:** `brethorsting.com` 是用 Bridgetown（Ruby 静态站点生成器）构建的博客，URL 格式是 `/blog/YYYY/MM/slug/` 而非常见的 `/blog/slug/`。

**如何找到正确 URL（当 browser_navigate 404 时）：**
```bash
# HN Algolia API 返回 canonical URL
curl -sL "https://hn.algolia.com/api/v1/search?tags=story&query=domain+expertise+moat" \
  | grep -o '"url":"https://www.brethorsting.com/[^"]*"'
# 返回: https://www.brethorsting.com/blog/2026/05/domain-expertise-has-always-been-the-real-moat/
```

**Bridgetown 识别特征：** 页面源码有 `/_bridgetown/live_reload` JS，导航含 Bridgetown 链接。常见于 Ruby 社区博主。

**教训：** HN 热帖外链 404 时，先用 HN Algolia API 查 story 找 canonical URL，再决定是否放弃。
