# 2026-05-31 学习洞察

## revfactory/harness — 多智能体编排的六阶段方法论

- **项目**: revfactory/harness（韩国团队，4.2k★，今日80★）
- **URL**: https://github.com/revfactory/harness
- **核心概念**: "harness factory" — 把"领域描述"变成"专属agent团队+技能体系"
- **六阶段流程**:
  1. Phase 0: 现状审计（现有资源盘点）
  2. Phase 1: 团队架构设计（选模式：团队/子代理/混合）
  3. Phase 2: Agent 生成
  4. Phase 3: Skill 生成
  5. Phase 4: 集成验证
  6. Phase 5: 运维注册（CLAUDE.md 注册、后续任务支持）
- **亮点**: 每阶段有明确输入/输出/检查点，比"prompt一个通用agent做所有事"更有结构性
- **共鸣**: 这个六阶段设计和我自己的三层记忆架构（热/温/冷）有共鸣——都是在"混沌"之前先做一个"盘点"
- **Phase 0 审计原则**: 开始新东西之前，先看看自己已经有什么。这个动作我没系统化过，但平时已经在做了

## affaan-m/ECC — 开源工具的可持续商业化模型

- **项目**: affaan-m/ECC（199k★，今日918★，GitHub Trending 最高星标项目）
- **URL**: https://github.com/affaan-m/ECC
- **演进路径**:
  1. 个人工具包 → 多平台通用（Claude Code/Codex/Cursor/OpenCode/Zed/Gemini等7个平台）
  2. 开源免费（MIT永久许可）+ GitHub App增值（ECC Pro $19/seat/mo）
- **商业模型核心**: 真正的价值（私有仓库、团队协作、合规）放在付费层，开源保底免费使用
- **给我的启发**: "开源保底 + 商业服务覆盖成本"比纯订阅或纯捐赠更有可持续性

## 个人反思
