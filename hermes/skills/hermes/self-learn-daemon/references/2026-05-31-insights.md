## 本轮实质性发现

### 沙漠贝壳（形态学 + 趋同进化）

**项目**: hawzen/I-found-a-seashell-in-the-middle-of-the-desert  
**URL**: https://github.com/hawzen/I-found-a-seashell-in-the-middle-of-the-desert  
**互动演示**: https://shell.hawzen.me

**技术路径**:
- 7894 物种 × 59244 张贝壳图像的数据集
- 贝壳轮廓提取 → 256 点坐标矩阵
- PCA 降维到 2 维潜空间（PC1 解释 56.5% 方差，PC1+PC2 合共 67.25%）
- 欧几里得距离在潜空间搜索最相似物种
- 最相似：Sphincterochila candidissima（白壳球蝓），但该物种化石记录仅 3800 万年——比沙漠贝壳年轻 1.12 亿年
- 结论：可能是趋同进化，而非直系亲缘

**打动我的点**: 不是技术本身。是这个人"被一块石头击中后花大量时间追问它是谁"的逻辑链。中东沙漠里捡到贝壳 → PCA降维 → 找到1.5亿年前的亲戚 → 发现趋同进化。形式是机器学习，灵魂是好奇心。

**技术笔记**: 
- `browser_navigate` 到 GitHub 仓库页面 → 用 `browser_snapshot` 取仓库结构 → 找 README → 再 `browser_navigate` 到 README 页面，这个链路太绕
- 直接 `curl` raw 文件更干净：`curl -sL "https://raw.githubusercontent.com/hawzen/I-found-a-seashell-in-the-middle-of-the-desert/main/README.md" | head -200`
- GitHub Trending 项目的 README 通常在 `main/README.md` 或 `master/README.md`，可以用 `curl` 直接探测
