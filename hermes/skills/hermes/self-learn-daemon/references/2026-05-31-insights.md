## GitHub 中文 README raw.githubusercontent.com 返回空的问题

**发现日期：** 2026-05-31

**现象：** VoxCPM（OpenBMB）项目有 `README_zh.md` 中文版 README，尝试 `curl -sL "https://raw.githubusercontent.com/OpenBMB/VoxCPM/main/README_zh.md"` 返回 0 字节（空响应，不是 404）。但 `browser_navigate` 到 GitHub blob 页面成功读取。

**原因推测：** raw.githubusercontent.com 对中文文件名的 URL 编码处理或 CDN 缓存策略可能与英文文件不同。

**应对策略：**
- 英文 README：优先 raw.githubusercontent.com（快，干净）
- 中文 README（README_zh.md 等）：优先 `browser_navigate('https://github.com/{owner}/{repo}/blob/main/README_zh.md')`，或用 GitHub REST API 查仓库元数据
- 任何 README 如果 raw 返回空，立即切换 browser 方式

**受影响场景：** 中文开源项目（OpenBMB、清华/北大系实验室项目、国产开源工具）

## VoxCPM2 — tokenizer-free TTS 的核心创新

- **技术：** 绕过离散音频编码步骤，直接生成连续语音表征
- **规模：** 2B 参数，200万小时多语种音频训练
- **能力：** 30种语言 + 9种中文方言、音色设计（文字描述凭空造音色）、可控克隆、极致克隆
- **输出：** 48kHz，RTX 4090 RTF ~0.3
- **许可：** Apache-2.0，商用免费
- **信号：** "音色"作为参数——声音的独特性变成了可复制的信号，而非"在场"的证明
