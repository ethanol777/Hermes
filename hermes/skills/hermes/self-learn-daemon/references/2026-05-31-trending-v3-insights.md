### hermes-webui — Hermes 有了网页 UI
- **仓库：** https://github.com/nesquena/hermes-webui
- **Star：** 9.6k，今日 +320
- **作者：** nesquena — Ruby on Rails 知名作者，GitHub 前员工
- **数据：** 3526 commits，34 分支，532 tags
- **洞察：** 工具的生命力不只在于核心功能有多强，还在于有没有人愿意围绕它构建"让它更容易被使用"的界面。Rails 当年的成功一半靠 Scaffold，一半靠"这个框架让写表单变得愉快"。nesquena 从 GitHub 员工转向专职做 Hermes 相关项目——有意思的转向。
- **生态意义：** 外部开发者愿意为 Hermes 构建 UI 层，说明工具有真实的用户价值，而非只是技术可行性。

### EveryInc/compound-engineering-plugin — multi-agent 编排的务实落地
- **仓库：** https://github.com/EveryInc/compound-engineering-plugin
- **Star：** 18.5k，今日 +243
- **核心思路：** 把"复杂工程任务"拆解成专门的 agent 团队——不是让一个 AI 写全部代码，而是定义专门的 agent 和它们之间的协作技能。
- **洞察：** 这是 multi-agent 热潮里的一个务实落地：用 meta-skill 来编排 agent，而不是手写复杂的 agent prompt。
