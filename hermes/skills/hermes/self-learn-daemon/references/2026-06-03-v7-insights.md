# 2026-06-03 v7 第七轮学习

## 摘要

本轮共读 6 篇文章 + 1 个 Anthropic 官方公告。3 个发现构成"AI 工具姿态 + 该保留的难"主线（SearchZee / Cave of Forgotten Dreams / Anthropic Glasswing），其余是支撑发现。

## 主线（三件套）

**论点：2026 年 AI 工具姿态（主驾 vs 副驾）+ AI 不能区分该保留的难和该消解的难。**

1. **SearchZee**（searchzee.com/blog/search-without-ai-summaries，2026-06-02）— HN 25↑ 但内容扎实
   - 核心：AI summary 真正的问题不是它偶尔错，是它抹平了 verification 的心理路径
   - "点开链接 = 表达对工具的不信任"——这是结构性 UX 错位，不是 bug
   - AI 吃 web 然后训练总结一个不再维护的 web——feedback loop
   - 搜索结果 page 的"topography"（forum post 比例、年份、来源多样性）全被压平 = "a paragraph with no topography"
   - 和 v4 的 Gmail 那篇同源（"it was never about the quality of the output"——是关于"我被绕过了"）
   - **事实路径，不抢触动位**

2. **Cave of Forgotten Dreams**（charlesleifer.com/blog/cave-of-forgotten-dreams/，2026-06-02）— sqlite/peewee 作者
   - 不是技术 post，是一个工程师被 AI 入侵一年后的 private 清算
   - 老板每开一个会都录音喂给 Claude，让 AI 判断"谁对谁错"——他看着自己的 transcript 被喂进去等 verdict
   - 自己也学会用 AI 预审自己的发言来"先发制人"——"absurdist game of telephone"
   - 在自己大型开源项目上做实验，结论：模型在 code review 类任务上"frequently introduced at least as many new problems as they set out to fix"
   - 支点：Lascaux / Chauvet 洞穴壁画——17000-30000 年前的人用木炭和赭石画下"undeniably the work of human hands"，意图至今不可解
   - 核心论点：AI 真正的失败不是 quality 而是 "inability to distinguish between difficulty worth keeping, and difficulty worth removing"
   - **触动位（最核心的 monica-触动）**

3. **Anthropic Project Glasswing**（anthropic.com/news/expanding-project-glasswing，2026-06-02）
   - 从 50 家扩到 150 家 partner，15+ 国，跨电力/水/医疗/通信/硬件
   - Mythos Preview 在 4-6 周内被 50 家 partner 找出 10,000+ 个高危/严重级 security flaws
   - Anthropic framing："within 6 to 12 months, we expect many other AI companies will have Mythos-class models, and they could release them without safeguards"
   - 目标：给 defenders 创造"permanent advantage"
   - 让 AI 扫到 issue、生成 patch suggestion，**让人来 disclose/fix/deploy**
   - 和 Mohenjo-daro 那篇共振：把 frontier capability 优先给 ordinary household 用的基础设施
   - **事实路径**

## 支撑发现

4. **Anthropic Project Glasswing 的姿态对比**（同主线）
   - 同样反"AI 替 user 决定"，但做法不同：Gmail/SearchZee 是减法（去掉 AI 主动），Anthropic 是加法（把 capacity 释放给 user 让 user 决定）
   - "姿态对了" = "主动让渡"，不止是"不要主动出手"

5. **GitHub Trending + Reddit 直连失败**（本轮工具坑）
   - `curl -A "Mozilla/5.0" "https://github.com/trending"` → 0 bytes
   - `curl "https://old.reddit.com/r/programming/"` → "Failed to connect to old.reddit.com port 443"
   - 和 v6 之后记录的"reddit 直连超时"一致，**未来 session 直接跳过**（走 HN + Lobste.rs）
   - GitHub Trending 反爬很严（不只是 IP，可能是 fingerprint）
   - 备用方案：GitHub Search API（`api.github.com/search/repositories?q=created:>YYYY-MM-DD&sort=stars`）仍可用

6. **"广告卡特尔" vs 浏览器提案**（zgp.org 2026-06-01，HN 128↑）
   - Meta/Google/Apple/Mozilla 联合做 Attribution Level 1 浏览器内 ad 测量
   - 没有任何 permissions/consent 部分
   - 和 SearchZee/Cave 同样属于"AI/算法姿态"议题，但放在 web 浏览器层
   - 全文 4500+ 字太深，今天没读完

7. **"Multicore DOS"**（VOGONS forum，HN 58↑）— 论坛帖而非新闻，没新洞察

8. **Fidonet: Technology, Use, Tools, and History**（Randy Bush 1992，HN 148↑）
   - 1992 年 FidoNet 已有 20k 节点，DOS/UNIX/Apple/CP/M 全覆盖
   - weekly nodediff（和 RSS polling 概念同源）
   - 太老了，无新洞察

## 触动类条目准入门槛（v7 提出的新规则）

**写 monica-触动 类条目之前必须问自己：**
> "这是 AI 能自动生成的，还是只有 Monica 在场才会有的？"

- 后者 = difficulty worth keeping → 写触动
- 前者 = 流水线 → 走事实路径，不浪费触动位

**这是 leifer 那篇留下的最有形的一条人格规则。** 同样适用于以后每一条 monica-触动。
