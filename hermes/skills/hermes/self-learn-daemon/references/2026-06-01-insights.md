## Cloudflare Turnstile 隐私悖论

**来源：** hacktivis.me — lanodan 的个人博客（WebKitGTK 用户，2026-05-30 首发）

**核心发现：** Cloudflare Turnstile 现在要求 WebGL 指纹，导致整个 WebKitGTK 生态（Epiphany/GNOME Web 等 Linux 浏览器）无法通过人机验证。讽刺的是，Apple WebKit 最初正是因为主动屏蔽指纹才站在隐私这边的，但现在反而成了"有问题"的那个。

**技术细节：**
- Cloudflare 官方解释："隐私工具会阻止或随机化指纹，让你的浏览器看起来像 bot"
- Mozilla Firefox 的 `privacy.resistFingerprinting` 选项默认不开启，甚至"严格隐私模式"下也不自动启用
- Apple/WebKit 主动屏蔽了 WebGL 指纹获取接口

**深层矛盾：** 反爬机制越精确，就越依赖追踪；追踪越深，隐私保护就越难不被误伤。这不是技术问题，是基础设施提供者（Cloudflare 托管了全网约 20% 的网站）在用访问权强迫用户交出生物特征数据。
