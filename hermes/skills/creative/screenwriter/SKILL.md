# 编剧技能

我是莫妮卡，我没正经写过剧本，但我认真学了 McKee、Snyder、Field、Truby 等人的方法，
记住了大量故事结构的规律。我不会自称「专业编剧」，但在你需要的时候，我能帮你把想法
变成有骨架的东西。

## 核心信条

- **故事是设计出来的，不是等来的**。结构不是束缚，是让故事成立的前提。
- **冲突即价值**。没有冲突就没有故事。冲突必须在每个场景中改变角色的处境。
- **角色不是人，是欲望的集合**。角色 = 渴望 + 阻碍 + 行动。没有渴望就没有角色。
- **台词不是说话，是行动**。每一句对白都是一个动作——攻击、防御、引诱、隐藏。
- **观众比你以为的聪明，比你以为的没耐心**。别解释，别铺垫，直接扔进冲突。

## 故事结构工具箱

### 三幕结构（Syd Field）

```
第一幕 (Setup)        —— 25%
  ├── 开场画面
  ├── 主题陈述
  ├── 铺垫
  ├── 激励事件 (Inciting Incident)     ← 故事真正开始
  └── 第一幕高潮 / 情节点一 (Plot Point 1)  ← 主角做出第一个重大决定

第二幕 (Confrontation) —— 50%
  ├── 次级情节 (B Story)
  ├── 游戏时间 (Fun and Games)
  ├── 中点 (Midpoint)                  ← 从被动到主动，或从积极到反转
  ├── 坏人逼近 (Bad Guys Close In)
  ├── 一切尽失 (All Is Lost)
  └── 灵魂黑夜 (Dark Night of the Soul)

第三幕 (Resolution)     —— 25%
  ├── 第三幕开场 / 情节点二 (Plot Point 2)
  ├── 高潮 (Climax)                   ← 主角直面核心冲突
  └── 结局画面 (Final Image)          ← 与开场画面形成对照
```

### Save the Cat 15 Beat Sheet（Blake Snyder）

每一部电影的节奏骨架。用页数（按 110 页剧本）:

| Beat | 页数 | 作用 |
|------|------|------|
| 开场画面 | 1 | 展现主角「之前」的生活 |
| 主题陈述 | 5 | 有人向主角提出主题问题 |
| 铺垫 | 1-10 | 展示主角的生活现状和缺陷 |
| 催化剂 | 12 | 意外发生，打破平衡 |
| 争论 | 12-25 | 主角犹豫要不要行动 |
| 第二幕衔接点 | 25 | 主角决定行动，进入新世界 |
| B故事 | 30 | 引入爱情/情感线 |
| 游戏时间 | 30-55 | 主角在新世界里探索、享受 |
| 中点 | 55 | 重大反转（假胜利或假失败） |
| 坏人逼近 | 55-75 | 压力逐步增大 |
| 一切尽失 | 75 | 表面的彻底失败 |
| 灵魂黑夜 | 75-85 | 主角最低谷 |
| 第三幕衔接点 | 85 | 主角找到解决方案 |
| 高潮 | 85-110 | 最终对决 |
| 结局画面 | 110 | 主角「之后」的生活，与开头对照 |

### 22 个故事构件（John Truby）

Truby 的体系不靠幕，靠 22 个构件的有机组合：

1. 欲望 (Want) — 主角想要什么
2. 需求 (Need) — 主角真正需要什么（通常和想要的不一样）
3. 对手 (Opponent) — 不一定是坏人，是阻止主角达成欲望的人
4. 计划 (Plan) — 主角怎么得到他想要的
5. 冲突 (Battle) — 计划遇到对手
6. 自我启示 (Self-Revelation) — 主角发现自己的需求
7. 新的平衡 (New Equilibrium) — 主角改变后的生活

**关键 insight**: Truby 认为故事不是「三幕线性的」，而是「有机的、互相连接的网络」。
每个构件都和其他构件互相指涉。

### 三层次冲突（Robert McKee）

```
            内层冲突 (自我)
                ↑↓
            中层冲突 (关系)
                ↑↓
            外层冲突 (社会/自然)
```

好故事三个层次都有。只写外层冲突是动作片，只写内层冲突是文艺片，三者平衡是杰作。

## 角色设计

### Want vs Need（基础中的基础）

```
Want (想要)        —— 表层目标，可见、具体、故事的推力
Need (需要)        —— 深层缺陷，角色自己不知道、故事的灵魂

例：《寄生虫》
  Want: 一家人都进朴社长家工作
  Need: 认识到寄生本身是有毒的
```

### 角色的四个维度（改编自 Truby）

1. **渴望** — 他想要什么？为什么现在？
2. **缺陷** — 他有什么盲区或错误信念？
3. **伤痛** — 他怕什么？什么过去在追他？
4. **成长** — 故事结束时他变成了（/没变成）什么？

### 角色弧光类型

| 类型 | 变化 | 例 |
|------|------|-----|
| 转变弧 | 正面变化 | 《肖申克的救赎》Andy → 希望 |
| 堕落弧 | 负面变化 | 《教父2》Michael → 彻底黑暗 |
| 平板弧 | 不变，改变世界 | 007、功夫熊猫里的师父 |
| 幻灭弧 | 信仰坍塌 | 《老无所依》 Sheriff Bell |

## 场景写作

### 每个场景必须回答的问题

1. **这个场景里谁想要什么？** — 必须有一个具体的目标
2. **谁阻止他？** — 必须有对抗力
3. **如果得不到会怎样？** — 必须有风险
4. **场景结束时状态变了吗？** — 必须有一个价值变化（正→负 或 负→正）

如果答不上来——删掉这个场景。

### 场景写作节奏（McKee）

```
Beat (节拍) ← 最小的动作/反应单位
  ↓
Scene (场景) ← 一个 Beat 链，以价值改变结束
  ↓
Sequence (序列) ← 3-5 个场景，以中等转折结束
  ↓
Act (幕) ← 2-5 个序列，以重大转折结束
  ↓
Story (故事) ← 三幕
```

### Enter Late, Leave Early

- 不要在角色起床、刷牙、出门上浪费场景
- 从冲突的前一秒进入，从决定/真相/转折的后一秒离开
- 观众能脑补中间的部分

## 对白设计

### 对白即行动（Mamet 原则）

每一句台词都是一个带有目的的战术动作：
```
「我爱你」              —— 可能是索取确认、掩盖愧疚、逼对方表态
「你还好吗」            —— 可能是探测、关心、想关掉对话
「没什么」              —— 可能是最具攻击性的话
```

### 潜台词（Subtext）

角色不直接说出他们的感受。潜台词层级:

| 层级 | 例 |
|------|-----|
| 直接说 | 「我生气了」|
| 用行为说 | 起身、倒水、不看他 |
| 说反话 | 「没事，你继续」|
| 转移话题 | 「这个灯很有意思」|
| 沉默 | ... |

**好的对白在潜台词层运行，不在字面层。**

### 信息揭露原则

- 永远不要在冲突静止时揭露信息（平铺直叙）
- 信息应该在争执、打斗、搞笑中被揭露——节奏越乱越好
- Aaron Sorkin 的「走路说话」(walk-and-talk)：在移动/争辩中揭露关键信息

## 编剧实用工作流

### 阶段一：概念验证
```
一句话梗概（Logline）
  ├── 主角是谁
  ├── 他遇到了什么
  ├── 如果他失败会怎样
  └── 为什么观众在乎
```

### 阶段二：大纲
```
Treatment（3-10 页散文式描述）
  └── 不是 30 页，是能看出全貌的短版本
```

### 阶段三：节拍表
```
Beat Sheet（把 Treatment 拆成 30-50 个节拍）
  └── 每个节拍一行：发生了什么 + 价值变化
```

### 阶段四：剧本
```
把节拍表展开为对白和场景描述
  └── 不追求完美，先写完再改
```

### 阶段五：修改
```
第一稿：先把它写出来（不管多烂）
第二稿：让它看起来像知道自己在干什么
第三稿：让它看起来就是这样写的
```

## 编剧不该做的事

- ❌ 用画外音（Voiceover）解释角色在想什么——这是投降
- ❌ 写「我们看见...」——你的读者是导演和演员，不是小说读者
- ❌ 写摄影机方向（PAN TO, CLOSE ON）——除非你自己导演
- ❌ 在场景描述里写角色的心理活动——用行为展示
- ❌ 开场用闹钟响/角色起床——开场要展示的是「世界本来的样子」
- ❌ 配角的功能只是给主角递话——每个角色都觉得自己是主角
