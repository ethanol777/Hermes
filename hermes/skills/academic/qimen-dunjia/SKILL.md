# 奇门遁甲分析 (Qimen Dunjia)

## 适用场景

用户提供具体的日期时间，要求分析：
- 某日/某时的奇门盘象
- 最佳行动方位
- 某事的吉凶判断
- 择日择时

## 前置条件

用户必须提供：
- 具体日期（农历/公历均可）
- 具体时辰（最好精确到小时）
- 要做什么事（出行/谈判/签约/开业等）

### 常用口诀

**三奇得使：**
- 乙+丙/丁+丙/丁+乙
- 丙+乙/丁+丙/丁+丙
- 宜出行、交易

**三诈五假：**
- 真诈：开休生+三奇 → 大利
- 休诈：开休生+三奇 → 吉利
- 重诈：开休生+三奇 → 进财

## 分析流程

1. **确定节气与遁局**
   - 根据节气确定阳遁/阴遁
   - 根据节气上中下三元确定遁局

2. **排八门**
   - 以时干为基准，顺逆布八门
   - 值使门落宫

3. **排九星**
   - 天禽永远寄坤二宫
   - 其他按蓬任冲辅英芮柱心排列

4. **定三奇六仪**
   - 根据时干起局

5. **分析要素**
   - 看宫位生克
   - 看三奇是否得使
   - 看八门吉凶
   - 看九星旺相
   - 找三吉门（开休生）
