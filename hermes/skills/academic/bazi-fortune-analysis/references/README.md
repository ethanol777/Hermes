# 参考文件目录

此目录存放八字命理分析的参考数据文件，源仓库：
https://github.com/jinchenma94/bazi-skill

## 文件清单

| 文件 | 内容 |
|------|------|
| `classical-texts.md` | 九本经典典籍的核心论命规则摘要（《穷通宝典》《三命通会》《滴天髓》《渊海子平》等） |
| `wuxing-tables.md` | 五行、天干地支、十神、藏干等所有参考表 |
| `shichen-table.md` | 时辰对照表、日上起时法（五鼠遁元）完整对照 |
| `dayun-rules.md` | 大运顺逆排规则、起运年龄计算、流年分析规则 |

## 使用方法

排盘计算时先读取对应的参考文件：
1. 排四柱 → `shichen-table.md` + `wuxing-tables.md`
2. 排大运 → `dayun-rules.md`
3. 综合分析 → `classical-texts.md`
