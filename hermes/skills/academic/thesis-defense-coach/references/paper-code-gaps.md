# 论文-代码差异点清单

> 答辩演练中发现的论文描述与实际代码不一致或有遗漏的地方，提前标注以便老师追问时从容应对。

## 1. 加权 L1 损失权重——论文没写

**论文：** 公式（2-9）只写 $\mathcal{L} = \mathcal{L}_{L1} + \lambda \cdot \mathcal{L}_{LB}$，实验3.2.2只说"L1回归损失"

**代码（`finetune.py` 第444-487行）：** 实际是逐维加权的 L1 损失

```
loss = 0.12×loss_x + 0.12×loss_y + 0.30×loss_z
     + 0.12×loss_rx + 0.12×loss_ry + 0.12×loss_rz
     + 0.10×loss_grip
```

**答法：** "论文里统一写为 $\mathcal{L}_{L1}$，代码实现中针对机器人动作不同维度的物理意义做了加权。z 轴权重 0.30 是因为高度误差对抓取成功率最敏感——偏一点就撞桌面或抓空。夹爪 0.10 是因为它接近二值（开/合），不需要精细回归。这个加权方案是工程经验设定，没有做消融验证。"

## 2. 训练精度（bf16/autocast）——论文没写

**论文：** 实验设置只写了学习率、batch size、优化器，未提数值精度

**代码（`finetune.py`）：** 三层精度控制
- `module.to(torch.bfloat16)` — 权重转 bf16，显存砍半
- `torch.autocast("cuda", dtype=torch.bfloat16)` — 自动混合精度
- 优化器状态（AdamW 一阶矩/二阶矩）在 fp32 维护

**策略：** 老师不问就不提。如果问"训练中数值精度怎么控制的"，从代码回答。bf16 比 fp16 动态范围大，MoE 训练中不同专家的梯度差异大，fp16 容易下溢。

## 3. AAE（精度误差）数据来源——论文表述模糊

**论文：** "取训练后5K步的算术平均值"（3.3.3节）

**实际：** 这些值来自**训练 log（每步训练集上的 L1 损失）**，不是独立测试集或 rollout 时的评估误差。所以描述的是"模型在训练数据上的拟合精度"，不是"在仿真环境中执行后的真实物理偏差"。

**局限：**
- 训练集误差 vs 评估误差：两者含义不同
- 反归一化公式 $0.5 \times L1_{norm} \times (q99-q01)$ 是**线性近似**——实际动作分布不是均匀的，q01-q99 两端稀疏
- 单步误差，**没有时序累积效应**——实际 rollout 时前一步误差到下一步会累积
- 夹爪维度 q01=0, q99=1，归一化范围 [-1,+1] 和物理范围 [0,1] 不对齐

**答法：** "这个精度误差是辅助指标，和成功率放在一起看才有意义。不能反过来说——动作误差小不等于 rollout 成功率高。"

## 4. MoE 层位置——文本表述有歧义

**论文：** "前12个残差块"

**代码（`action_heads.py`）：**
```python
for block_idx in range(24):
    use_moe = use_moe and (block_idx >= moe_start_layer)
```
`moe_start_layer=12` → `block_idx >= 12` → **块 12~23（靠近输出侧的 12 层）** 启用 MoE，不是从输入侧数的前 12 层。

**答法：** "论文里'前12个残差块'的表述有歧义。代码中 moe_start_layer=12 控制，实际输出侧的 12 层启用 MoE。靠近输入侧的浅层特征偏通用感知不需要分工；靠近输出侧的特征进入动作语义空间后，MoE 的容量扩展收益最大。"

---

## 5. 消融实验 vs 超参数扫描——术语不严谨

**论文：** 第4章标题"消融分析"

**实际：** N={2,4,8} × λ={0,0.01,0.1} 是**超参数扫描（hyperparameter sweep）**。真正算消融的是：
- 移除 MoE（退化为基线）→ 验证整体贡献
- λ=0（移除负载均衡）→ N=8 时 Object 从 97% 暴跌到 3.4%

**答法：** "您说得对，'消融'严格指移除组件看性能下降。N 和 λ 的多值对比应该叫超参数敏感性分析。论文标题写'消融分析'不够严谨。"
