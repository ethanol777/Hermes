# 紫微斗数命盘分析 (Ziwei Doushu)

## 适用场景

用户提供了完整的紫微斗数命盘数据，要求分析：
- 命格高低与命盘结构
- 各宫位吉凶
- 大限/流年运势
- 具体事项（事业、感情、财运）

## 前置条件

用户必须提供：
- 性别
- 出生年月日时（用于确认命盘）
- 完整的十二宫垣排列（最好有星曜分布）
- 具体要问什么

### 常用格局

**紫微系格局**
- 紫微天府：领导型
- 紫微天相：辅佐型
- 紫微贪狼：欲望型
- 紫微七杀：威权型

**重要结构**
- 杀破狼：变动格局
- 阳梁昌禄：考试成名
- 机月同梁：稳定型
- 巨机同临：口才发财

## 分析流程

1. **确认命盘结构**
   - 命宫在哪一宫
   - 命宫有哪些主星
   - 有无紫微星系

2. **判断命格**
   - 星曜组合（群星聚伺与否）
   - 四化飞入情况
   - 宫位得地与否

3. **分析各宫**
   - 重点看命宫、事业宫、财帛宫、夫妻宫
   - 看三方四正配合

4. **运势分析**
   - 大限宫位
   - 流年引发
