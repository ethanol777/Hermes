# 本科毕业设计评语写作指南

## 文体定位

评语是答辩委员会/指导教师在学生完成毕业答辩后给出的**学术评价文书**。不是指导信、不是反馈意见，而是对已完成工作的结论性评价。

## 结构模板

评语通常包含以下要素（按出现顺序）：

1. **研究问题定位**（1-2句）：论文针对什么问题/场景展开研究
   - "该论文围绕……问题展开研究"
   - 包含：问题域 + 方法/架构关键词

2. **方法描述**（1-2句）：用了什么方法、做了什么改进
   - "结合……方法，提出了……框架/策略/模型"
   - 点名核心技术：不要只写"提出了一种方法"，要写"提出了基于稀疏MoE的……"

3. **技术路线评价**（1句）：结构是否清晰、理论+实验结合是否好
   - "论文技术路线清晰，结构完整，能够较好地将理论分析与实验验证相结合"

4. **实验结论**（1-2句）：结果如何、在哪些维度有提升
   - "实验结果表明，所提出方法在XX基准上取得了优于基线的表现"
   - 报关键指标（如平均成功率、提升百分点），但不需要全部数字
   - 可以点出具体的改进维度（如"对长时序任务的策略稳定性有明显改善"）

5. **消融/分析评价**（1句）：实验设计是否严谨
   - "消融实验设计较为系统，揭示了XX超参对XX的影响规律"
   - 这里的重点是"揭示规律"而非"验证有效性"

6. **工程/实践能力**（1句）：代码/系统实现质量
   - "同时，作者完成了XX的设计与实现，展现出较强的工程实践能力"

7. **结论**（1句）：工作量是否达标、是否通过
   - "论文工作量较充实，达到本科毕业论文要求，同意通过结题验收"

## 语言风格规范

### DO
- **客观平实**：陈述事实而非表态。"实验结果表明……"而非"我认为……"
- **精准克制**：不用夸张修饰。"均有优于基线的表现"而非"表现出显著的优越性"
- **动词驱动**：用"揭示""验证""展现""完成""提出"这类行动性强的动词
- **点到为止**：只说"达到本科毕业论文要求"，不需要额外褒扬

### DON'T
- ❌ 不要使用"我""我们""本人在阅读后认为"——评语不是个人感想
- ❌ 不要过度赞美——"优秀的""杰出的""令人印象深刻的"不符合评语文体
- ❌ 不要具体报错——评语不在这里指出论文缺陷（那是答辩问答环节的事）
- ❌ 不要写长句——每个句子控制在30-40字内，清晰为主

### 句式范例

| 推荐 | 不推荐 |
|------|--------|
| "论文技术路线清晰" | "这篇论文的写作很有条理" |
| "实验结果表明……" | "我认为实验结果很好" |
| "揭示了……的影响规律" | "揭示了很有价值的规律" |
| "展现较强的工程实践能力" | "工程能力蛮强的" |
| "达到本科毕业论文要求" | "是一篇优秀的毕业论文" |

## 关键注意事项

- **评语是结论，不是建议**：不要出现"可以进一步""建议补充""未来可做"——这是论文本身未来工作里的内容，不属于评语
- **一致性**：全文字数控制在200-350字，风格统一
- **第一句定调**：开头第一句直接点出"该论文围绕XX问题"，定位整篇评语
